Thuộc Tính Position: static • relative • absolute • fixed

Chọn giá trị position:
Điều chỉnh tọa độ (Offsets):
top: 30px
left: 40px
Thẻ cha (.parent-box) làm mốc tọa độ cho absolute.
static (Mặc định)

Nằm trong luồng tự nhiên

Phần tử hiển thị theo thứ tự mặc định của HTML. Các thuộc tính top, left bị bỏ qua hoàn toàn.

Khung hiển thị giả lập (Cuộn để kiểm tra fixed): Dùng chuột cuộn khung bên dưới
#1 Khối tĩnh phía trước (static)
<div class="parent-box"> (position: relative)
Vị trí gốc ban đầu
Target Box top: auto, left: auto
#2 Khối tĩnh phía sau (static)
#3 Khối tĩnh bổ sung (static)
#4 Khối tĩnh chân trang (static)
Quy tắc CSS áp dụng:
.target { position: static; }
