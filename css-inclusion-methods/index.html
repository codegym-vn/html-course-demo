Ba Cách Nhúng CSS: Inline • Internal • External

Bật/tắt các nguồn CSS để xem quy tắc nào chiến thắng:
Ưu tiên cao nhất
<p style="color: #ef4444; font-weight: bold;">
Ưu tiên trung bình
<style> p { color: #22c55e; text-decoration: underline; } </style>
Ưu tiên cơ bản
/* style.css */
p { color: #3b82f6; font-style: italic; }
Nguyên lý Cascade (Xếp tầng): Trình duyệt sẽ ưu tiên Inline Style đè lên Internal và External. Khi 2 quy tắc có cùng độ ưu tiên, quy tắc nào được khai báo sau sẽ giành chiến thắng.
Màu chiến thắng: Inline CSS (#ef4444 - Đỏ)
