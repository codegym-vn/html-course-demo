Nghệ thuật Typography trong thiết kế Web

Typography không chỉ là việc chọn một phông chữ đẹp mắt. Đó là sự cân bằng tinh tế giữa cỡ chữ (font-size), độ giãn dòng (line-height) và độ tương phản màu sắc giúp người đọc tiếp thu thông tin tự nhiên, không mỏi mắt.

Đoạn mã CSS áp dụng:
p { font-size: 16px; line-height: 1.6; text-align: left; }
