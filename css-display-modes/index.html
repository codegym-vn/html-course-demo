Khảo Sát Display: block • inline • inline-block

Chọn giá trị display:
Thiết lập thuộc tính thử nghiệm:
width: 140px
Bị bỏ qua khi ở chế độ inline
height: 50px
Bị bỏ qua khi ở chế độ inline
margin (dọc trên/dưới): 16px
margin dọc không đẩy dòng trong inline
Xuống dòng mới (Line Break) Không
Áp dụng width / height Không hiệu lực
margin trên / dưới Không hiệu lực
Luồng hiển thị tài liệu (Document Flow):
Thẻ Trước (#1)
Target Box inline
Thẻ Kế Tiếp (#2) Thẻ Kết Thúc (#3)
Hành vi inline: Chảy liên tục trên cùng dòng với các thẻ khác. Không thể can thiệp width, height và margin trên/dưới.
Quy tắc CSS hiện tại:
.target { display: inline; /* width & height bị bỏ qua */ }
