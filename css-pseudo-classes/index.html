Lớp Giả CSS: :hover • :focus • :nth-child()

Mô phỏng trạng thái kích hoạt:
:hover

Kích hoạt khi rê chuột

Áp dụng kiểu dáng đặc biệt khi người dùng di con trỏ chuột lên trên phần tử.

Mẹo: Bạn cũng có thể dùng chuột rê, bấm hoặc Tab bàn phím trực tiếp vào các phần tử ở khung bên phải để trải nghiệm trạng thái thực tế.
Khu vực thử nghiệm tương tác:
Nút bấm tương tác (.btn-demo):
Ô nhập liệu (.input-demo):
Quy tắc CSS sinh ra:
.btn-demo:hover { background-color: #0284c7; transform: translateY(-2px); }
Chọn mẫu công thức nhanh:
:nth-child( )
Các số thứ tự phần tử được khớp:
1, 3, 5, 7, 9

Khi n = 0, 1, 2, 3, 4,... công thức odd đại diện cho các số lẻ.

Danh sách phần tử trong cùng thẻ cha (.list-container):
Quy tắc CSS áp dụng:
.item:nth-child(odd) { background-color: #0284c7; color: #fff; }
