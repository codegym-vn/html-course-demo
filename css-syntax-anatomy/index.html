Giải Phẫu Cú Pháp CSS: selector { property: value; }

Thành phần của một quy tắc CSS:
Selector .btn {
Property color : Value #ffffff ;
Property background-color : Value #2563eb ;
}
Mô phỏng tình huống cú pháp:
Cú pháp hoàn toàn hợp lệ

Trình duyệt đọc hiểu trọn vẹn Selector và khối Declaration Block, áp dụng cả 2 thuộc tính color và background-color.
