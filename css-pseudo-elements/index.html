Phần Tử Giả: ::before • content • ::after

Chọn ứng dụng thực tế:
Kích hoạt phần tử giả:
Nếu thiếu content, phần tử giả sẽ biến mất hoàn toàn.
Nguyên tắc vàng: ::before và ::after được tạo ra bên trong phần tử mục tiêu, đóng vai trò như thẻ con đầu tiên và con cuối cùng.
Sơ đồ phân lớp phần tử giả trong DOM:
::before "“"
Nội dung thật (Element Content) "Kiến thức là sức mạnh"
::after "”"
Kết quả hiển thị trên trình duyệt:
Kiến thức là sức mạnh
Quy tắc CSS áp dụng:
.box::before { content: "“"; font-size: 2rem; color: #38bdf8; }
