Mặc định của CSS

box-sizing: content-box

width chỉ áp dụng cho vùng Content. Padding và Border cộng dồn làm phình to hộp ra ngoài.

Vạch định mức khai báo: 240px
Content Area
Kích thước hiển thị thực tế: 292px
240px (width) + 40px (padding) + 12px (border)
Khuyên dùng trong thực tế

box-sizing: border-box

width bao gồm cả Content, Padding và Border. Hộp luôn giữ đúng kích thước định sẵn.

Vạch định mức khai báo: 240px
Content Area
Kích thước hiển thị thực tế: 240px
Giữ nguyên 240px (Content tự co lại còn 188px)
Chuẩn công nghiệp: Luôn áp dụng CSS Reset toàn cục để giao diện không bị vỡ layout do padding.
* { box-sizing: border-box; margin: 0; padding: 0; }
