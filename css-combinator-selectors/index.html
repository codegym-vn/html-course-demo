Bộ Chọn Kết Hợp: Descendant • Child • Sibling

Chọn loại bộ chọn kết hợp:
Khoảng trắng (Space)

Bộ chọn Hậu duệ: .card p

Chọn TẤT CẢ các thẻ <p> nằm bên trong .card, bất kể chúng là con F1, cháu F2 hay nằm sâu bao nhiêu cấp.

Số phần tử được khớp: 3 phần tử
Cấu trúc phân cấp tài liệu (.card):
<div class="card">
<h3> Tiêu đề bài viết </h3> Mốc chuẩn (Anchor)
<p> Đoạn mở đầu (Con F1 - Liền kề sau h3) </p> MATCH
<div class="sub-box">
<p> Đoạn trích dẫn (Cháu F2 - Nằm trong .sub-box) </p> MATCH
</div>
<p> Đoạn kết luận (Con F1 - Cùng cấp sau h3) </p> MATCH
</div>
Quy tắc CSS được áp dụng:
.card p { color: #38bdf8; font-weight: 700; }
